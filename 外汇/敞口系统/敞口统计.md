# 敞口统计

## 1. 业务定位

基于公司外汇交易，进行全局指标统计，以便交易员对未知风险进行控制。指标以 法律主体，账薄，交割日，货币对 为维度 结合 汇率波动进行统计 日损益，月损益，年损益，提润等逻辑。

## 2. 指标公式

日损益 =  （今天收盘汇率 - 昨天收盘汇率）\* ccy1总敞口

月损益 =  累加一月的（日损益）

年损益 = 累加12个月的（月损益）

提润  =  提取 日损益
